# 기념품 신청

레포에는 **`index.html` 하나**뿐입니다. 명단도 접수 결과도 전부 구글 스프레드시트에 있습니다.

```
스프레드시트  시트1      참가자 명단        ← 직접 관리
             신청내역    접수 결과          ← 자동 생성
GitHub Pages index.html  화면 + 기념품 설정
             images/     (선택) 대표 이미지를 직접 올릴 때
```

---

## 1. Apps Script 배포 (10분)

1. [스프레드시트](https://docs.google.com/spreadsheets/d/1P9bgchqFiJMl0OYXGDLy7_rWGNPz4Iss19ZUYvIYB24/edit)를 엽니다
2. **확장 프로그램 → Apps Script**, 기본 코드를 지우고 `Code.gs` 내용을 붙여넣고 저장
3. 편집기에서 `명단확인` 함수를 실행합니다 — 권한 승인 창이 뜨고,
   로그에 `총 45개 협력사`가 찍히면 명단 읽기가 정상입니다
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** ← 이걸 안 바꾸면 제출이 전부 실패합니다
5. 나오는 `.../exec` URL을 `index.html`의 `API` 값에 붙여넣습니다

`신청내역` 시트는 첫 제출 때 자동으로 만들어집니다. 결과가 필요하면 그 시트에서
**파일 → 다운로드 → CSV**로 받으면 됩니다.

## 2. 레포 올리기

`index.html`을 새 레포 루트에 올리고
**Settings → Pages → Source: Deploy from a branch → main / (root)**.
1~2분 뒤 `https://<아이디>.github.io/<레포이름>/` 에서 열립니다.

## 기념품 설정

`index.html` 위쪽 `GIFTS` 배열에 3종이 들어가 있습니다.

| 항목 | 설명 |
|---|---|
| `show` | `false`로 두면 화면에서 숨겨집니다 |
| `name` / `desc` / `note` | 카드에 보이는 이름·설명·강조 문구. `desc`는 `\n`으로 줄바꿈 |
| `thumb` | 카드 썸네일. 비우면 `detail`의 첫 이미지 윗부분을 씁니다 |
| `options` | 색상처럼 고를 것이 있을 때만. 있으면 3단계에 선택칸이 생기고 시트 `옵션` 열에 기록됩니다 |
| `detail` | "자세히 보기"에 세로로 이어 붙일 상세페이지 이미지. `{ title, images }` 묶음이라 2종 구성처럼 섹션을 나눌 수 있습니다 |

현재 들어간 내용:

- **A** LG 디오스 오브제컬렉션 와인셀러 8병 (W0082GLE, 크림 라벤더)
- **B** 선일금고 아트 금고 UP-040 (김지희 작가 에디션)
- **C** 코지마 마사지기 2종 세트 — 저주파 마사지기 CMA-E106WL + 발마사지기 코지스툴 CMF-140/150
  - 색상 선택: 워시드 그레이(CMF-140) / 워시드 아이보리(CMF-150)

## 이미지 관련해서 꼭 확인하실 것

**썸네일을 따로 준비하시는 게 좋습니다.** 지금 `thumb`에는 상세페이지 이미지를 그대로 걸어
놨는데, LG 상세페이지는 세로 14,408px짜리 한 장입니다. 카드에 작게 보여주려고 그 큰 파일을
통째로 받게 되니 모바일에서 첫 화면이 느려집니다. SK스토아 상품 대표이미지 URL이나
가로로 긴 사진 3장을 `images/`에 올려서 `thumb`에 넣어 주시면 해결됩니다.

```js
thumb: "images/gift-a.jpg",
```

**외부 이미지 링크가 막힐 수 있습니다.** `bokjung.com`과 `open.lge.co.kr` 이미지는 다른
사이트에서 불러가는 것을 막아두는 경우가 있습니다. 배포 후 실제 주소에서 "자세히 보기"를
열어 이미지가 다 나오는지 확인해 주세요. 안 나오면 `이미지를 불러오지 못했습니다`가 뜹니다.
그럴 때는 해당 이미지를 내려받아 `images/`에 올리고 경로만 바꾸면 됩니다.

## 명단 바꾸기

`시트1`을 고치면 바로 반영됩니다. 배포도 커밋도 필요 없습니다.
헤더는 `참가일자 / 협력사명 / 직위 / 참가자명` 이름만 맞으면 열 순서가 바뀌어도 동작합니다.

협력사명이 아이디라 **중복되면 첫 줄만 인식**합니다. 같은 회사가 두 번 참가하면
`(주)OO(9/22)`처럼 구분해서 적으세요.

## 알아두실 점

**화면에 처음 내려가는 건 일자와 회사명뿐입니다.** 직위·참가자명은 회사를 고른 사람에게만
따로 내려갑니다. 명단 전체가 한 번에 노출되지 않게 나눠 놨습니다.

**Apps Script 코드를 고친 뒤에는** "배포 관리 → 수정 → 버전: **새 버전**"으로 다시 배포해야
반영됩니다. 저장만 해서는 URL에 적용되지 않습니다. 여기서 막히는 경우가 제일 많습니다.

**`신청내역` 시트를 이미 만들어 두셨다면** 한 번 지우고 다시 만드세요. `옵션` 열이 새로
들어가면서 열 순서가 바뀌었습니다.

**참가일자가 날짜 값이어도 그대로 두셔도 됩니다.** 구글 시트는 `9/22`를 날짜로 자동 변환하는데,
`Code.gs`가 이를 `9/22(화)` 형태로 되돌려 놓습니다. 텍스트로 적혀 있으면 적힌 그대로 씁니다.
요일은 날짜에서 계산하므로 시트에 요일을 적지 않아도 됩니다.
